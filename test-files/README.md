# EcoSuitability manual test files

These fixtures are synthetic and intended only for local end-to-end testing. They are copies of
the reproducible example generated by `scripts/generate-example-dataset.py`.

## Upload through the frontend

1. Select **CSV** for the occurrence format and upload `synthetic-occurrences.csv`.
2. Upload `synthetic-elevation.tif` as an environmental predictor.
3. Complete the upload and wait for input profiling.
4. In Configuration, use:
   - species: `Example species`
   - longitude column: `longitude`
   - latitude column: `latitude`
   - predictor name: `elevation`
   - predictor type: `continuous`
   - evaluation: train/test split with `0.2` held out
   - terrain: optional; select `elevation` only to exercise the DEM checks
5. Save, wait for preflight to pass, queue the analysis, and follow the Run screen.

The remaining defaults are valid for this fixture. `manifest.json` contains the expected byte sizes
and SHA-256 checksums.
